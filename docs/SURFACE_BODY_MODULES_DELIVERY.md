# 已有曲面零件的功能模块接入

日期：2026-11-05。目录 `/workspace/lego-import-collision`，分支 `codex/surface-body-modules`，基准 `ba619e9`。

## 实际完成了什么

15068 曲面件从独立两件样例进入了可复用的三件车身覆盖核心：3022 支撑板、15068 曲面、3069b 收边。两种配方取自同一个许可明确的 75878 重建模型中的左右侧饰板，内部相对位置和零件身份均未修改。它们可以安装到多个真实基座，并能与另一个套装来源的既有上盖组成九件模型。

这是一个新增功能、两个来源变体，不是两个独立设计功能。左右指来源提取位置；最终模块整体朝向由真实接口求解。本轮没有建立全车轴向、左右车身位置、座舱比例或完整外形约束，样例不能称为完整车身、座舱或跑车。

没有新增原生零件或资格。15068 仍只使用受限表面合同，没有升级为承力或闭合实体资格。

## 为什么已有零件没有充分用起来

调用关系为：

`GrammarAssemblyService` 当前资格 → `NativeAssemblyGenerator` 来源候选 → `ModuleCatalog` 配方 → `ModuleAssembler` 内部复验与接口安装 → `AttachmentEngine` 占用/整体碰撞/连接图 → 文档导出与当前重导入。

双件 `exterior-shell` 入口已经能使用部分曲面和风挡。普通结构生长不会自动将它们作为结构件；现有配方也没有提供这些零件的功能组合。另一个实际阻塞在来源读取器：它会先解释父片段的全部 type-1 记录，遇到未选入模块的嵌套引用、带空格的局部文件名或近似旋转矩阵，就拒绝整个提取。

| 原生编号 | 解析接口 / 当前开放表面接口 | 当前状态与本轮用途 |
|---|---:|---|
| 15068 | 5 / 4 | 接入两种三件覆盖配方，六个正式生成样例实际使用 |
| 11477 | 2 / 2 | 双件能力保留；调查的一条 75878 路线受 3021/50950 来源姿态碰撞阻止，本轮没有功能配方 |

## 共性修复：明确提取范围

新增 `src/parts/modules/source.ts/readSelectedModuleMembers()`：先确定选中的原始 type-1 序号，仅解释这些记录的原生编号和刚体变换，再以选定入口做统一坐标归一化。

- 未选中的记录保留在完整原始片段中，不展开、不作为该模块的依赖或接口证据。
- 明确选中的记录仍必须是可读取的直接原生 `.dat` 引用和严格刚体变换。
- 选中嵌套/局部引用、近似非刚体矩阵、缺失序号和不一致的提取元数据时继续拒绝。
- 原文任意位置发生变化，包括未选中的记录，完整文件哈希检查仍会失败。
- 不解析装配图来创造连接点；所有连接继续来自既有真实零件与当前语法。

受控新旧对照给两种读取器提供相同的新审查清单，仅适配旧版清单 pin 与相对导入，不修改旧读取逻辑。旧函数拒绝这个父片段，新函数读取三件已明确选择的零件；把第 32 条局部资源或第 119 条近似变换纳入选择，新函数仍拒绝。适配范围、旧源码哈希和失败原因见 [reader-comparison.json](../artifacts/surface-body-modules/reader-comparison.json)。适配器只用于审查，不进入生产授权链。

## 保留的阻塞与诊断

`3021 + 50950` 是来源 75878 中继续向 11477 覆盖路线推进的一对前置成员。保持原相对姿态、使用当前开放接口后，原始外表面进入闭合材料的区域超出允许 seat，当前仍返回 `exterior-surface-crossing`。

[blocked-source-route.json](../artifacts/surface-body-modules/blocked-source-route.json) 保存原始序号、两件完整刚体姿态、来源与验证版本、接口、配合区域、代理证据、原始三角面/分区及见证位置。没有用预算失败冒充碰撞，没有改写源文件或放宽数值。本结论只针对该来源姿态，不证明所有 50950、11477 姿态都不可用，也不认定零售套装无法实物拼搭。

18973 的探索来源 75892 使用局部印刷引用 `75892 - 18973p01.dat`。本轮没有将它当作已验证的 18973 别名；探索性去印刷换件也没有建立完整合法连接。未发布该假设配方，未向生产库复制它。65633 尚缺本轮核定的多件来源结构。两个风挡继续维持既有双件能力，不计入本轮功能模块成果。

尾翼、轮组、安装轨迹、材料、保持力、实物和整车仍未验收。本轮未修改旧尾翼碰撞结论。
