## 从步骤图得到的有限观察

这些是待纳入设计知识的来源事实，不直接产生新零件或连接点。

- **轮销和车轮承载组件需要独立识别。** 6662707 第 12 页步骤 10–11 先做装有两根销的小组件；编号与连接规范尚需后续映射，不能仅凭图像写入接口坐标。
- **存在专用大底盘。** 6617283 第 12 页步骤 8 先翻转专用大底盘，再接入已有轮销的小组件。缺少这类零件的真实几何时，不应使用普通长方形板冒充。
- **曲面与侧面连接依赖多个零件和朝向。** 6592612 第 70 页步骤 73、6592556 第 70 页步骤 85 展示分开的轮拱、车身覆盖和座舱构建阶段。只画整体曲面不能替代真实拼接结构。

- **可见外观特征应保留为车型参考。** 6662707 封面有方形乘员舱、四圆灯、独立尾翼；6617271 封面有倾斜整体风挡和尾翼；6617283 封面有橙黑车身分区。没有从图片推断精确尺寸、零件弧度或接口位置。

每条观察在 manifest 的 `observations` 中保存确切页码、原文件哈希、`method=assistant-visual-review` 和 `humanApproved=false`。

## 可重跑的本地导入

`scripts/import-instruction-pdfs.py` 只读取显式指定的本地路径，不发起网络访问。需要 Python 和 PyMuPDF（本次环境已有）。例如：

```bash
python scripts/import-instruction-pdfs.py /path/to/6522905.pdf /path/to/6662707.pdf --output /path/to/output
```

也可传入本地目录。输出是一份所传文件的完整快照；如需保留原有文献，应同时传入原文件，或写入新的输出目录后再合并核对。原始 PDF 不会拷贝到输出目录；数据只记录文件名和哈希，不暴露绝对附件路径。如需私有页面图，额外指定 `--render-dir /tmp/pdf-review`。只有整理本轮原始八份上传时才使用 `--record-original-upload-gaps`，它会记录两个已知传输失败的文件，不能拿来推断其他批次的缺失原因。

内置的 54 行视觉抽查和有限步骤观察都绑定原文件 SHA-256；同名但字节不同的新文件不会继承已抽查状态。图片型 PDF 没有可提取文字时不会输出伪清单；应补充经过复核的 OCR/人工数据。该脚本没有自动 OCR、颜色识别、element→design 映射、全书步骤图理解或 PDF→3D 功能。
