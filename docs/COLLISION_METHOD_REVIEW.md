## 实际解决的问题

本轮把“反复测试不通过”拆成几类原因处理。修复了开放网格的共面接触范围误判、UNKNOWN 处理遗漏，还发现并修复了一个与碰撞无关的选件错误：只指定一个零件时，双件生成器错误地把这个编号同时用于筛选双方，导致合法组合根本没有进入装配验证。

网页新增独立的表面覆盖件选择器，可以明确选取已有曲面或风挡，再走正式接口、碰撞和重导入流程。没有增加零件来源或资格，没有把未知几何封成实体，也没有扩大碰撞容差。

## 两处碰撞修复

### 共面时只检查实际接触区域

旧路径位于 `collision.ts` 的开放网格分支：三角面包围盒重叠且共面时，直接检查两个三角形的全部六个顶点是否落在允许配合区内。这会把实际未接触的远端顶点当成越界接触；甚至两个共面三角形没有相交，包围盒也可能重叠。

新增 `surfaceContact.ts/intersectCoplanarSourceTriangles()`，用现有凸多边形半空间裁剪求公共区域，然后只检查公共区域的点。保留点、边、面接触；不因两点很近而丢弃其中一个，防止遗漏越界位置。无效、退化、无法确认共面的输入保持 UNKNOWN。

裁剪不向外扩张，既有 `0.0001 LDU` 比较容差和配合区域不变。计算的接触区域用于验证，没有修改任何源网格、制造厚度或填补孔洞。

数学回归包含：包围盒重叠但三角形不相交、实际接触区完全在配合区内而输入顶点在外、真实越界接触、边/点接触、反向绕序、共同刚体变换和近邻顶点。都是明确标注的算法三角形，不是虚构 LEGO 零件或接口。

### UNKNOWN 不再从开放网格顶点路径漏过

旧代码只在 `classifyPoint(...) === 'inside'` 时拒绝；返回 UNKNOWN 时仍可能走到最终 CLEAR。现在该路径复用 `assessSourceSurfaceCell()`，明确返回阻止，并记录未知顶点和来源三角面。PIN 的既有配合区规则保留，UNKNOWN 仍然不能授予通过。

同时让顶点分类阶段遵守原有计算时限。预算耗尽保持阻止，不冒充碰撞或通过。

这是代码路径和回归证明的遗漏修复，没有宣称已发现某个真实历史模型借此获得了错误准入。

## 选件错误才是另一类阻塞

`NativeAssemblyGenerator` 的 exterior-shell、bar-clip、pin-hole 都存在相同筛选问题：`requiredPartIds` 只有一个编号时，同时要求固定件和移动件都属于该单元素集合，又禁止相同编号，于是无法生成任何组合。

现在按请求语义检查最终候选对包含所有指定编号：

- 指定一个编号：它可位于连接任意一侧，另一侧由当前正式来源和接口规则选择。
- 指定两个编号：必须是这两个，不静默替换。
- 未知编号、两件结构件冒充表面目标、两个外壳冒充一件基座加覆盖件，仍拒绝。

在同一个当前装配引擎上运行旧/新选件代码，四项请求均从 BLOCKED 改为 GENERATED，且 JSON 重导入 VALID：

| 目标 | 只指定的已有零件 |
|---|---|
| 表面合同 | 11477 |
| 表面合同 | 3001 |
| Bar/Clip | 30374 |
| Pin/Hole | 3673 |

这个对照仅隔离候选筛选，双方均使用当前碰撞器；不能把成功归因于放宽碰撞。

网页保持原有结构件选择器，新增“表面覆盖零件”。从当前资格服务的 entries 中列出受限表面候选，不伪装成结构资格。点击“表面合同模块”时提交选择的真实基座和覆盖件；其他目标不会受到覆盖件选项影响。杆夹/销孔/表面固定双件目标使用两件数量，不再继承上一次九件组合的输入值。

## 是否需要更换碰撞方式

需要按失败原因选择方法。当前适合保留接口先求姿态、BVH 预筛选、实际接触区域与可靠分类的分层路线，替换已证实有问题的局部判断。

| 问题 | 合适处理 | 证明边界 |
|---|---|---|
| 曲面是开放显示网格，承担覆盖用途 | 明确 surface contract，用原始表面检查并依赖已验证骨架 | 不认证体积、厚度、承力或实物 |
| 真正闭合的原生实体 | 完整相交和包含检查 | 不能只看三角形是否相交 |
| 共面接触区域被算错 | 实际公共区域裁剪 | 不扩大整个零件或接口豁免 |
| UNKNOWN、预算或边界解释不足 | 记录原因，按问题补数据或升级算法 | 不用另一个工具“没报错”直接放行 |
| 源数字面有微小重叠 | 核对源精度、模型版本及可靠配合证据 | 高精度内核本身不会消除输入几何的重叠 |
| 轮胎/轮毂缺配合规则 | 补接口、座合与净空证据 | 更换碰撞库不能创造连接知识 |

体素、SDF、凸分解或通用物理引擎可以另做有界对照，但未经验证的分辨率、凸包填洞和材料参数不能用于当前放行。现阶段没有足够依据整套迁移。
