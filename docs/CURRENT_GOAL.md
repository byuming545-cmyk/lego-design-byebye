# 当前目标：原创 LEGO 跑车生成

更新日期：2026-11-04。依据用户最新指令，本目标取代之前“生成奔驰 S63”的成品目标；后续任务与旧记录冲突时，以本目标和用户后续指令为准。

## 最终成果

使用来源和许可明确的真实 LEGO 数字零件，自动生成独立设计的跑车。整车比例、模块布局、车头车尾和车身造型由本项目的目标约束与搜索过程形成。

不要求复现某一辆现实汽车或某套官方成品。通用跑车特征、合法拼搭方法及有许可的标准零件仍可复用；不直接复用已有整车的完整布局、标识和特色外观组合。保留设计简述、生成参数、候选选择及来源记录，支持原创设计过程复核。

## 保持的技术主线

真实零件库 → 接口语法 → 装配验证 → 正式生成 → 模型、BOM、拼搭步骤 → 导出与重新导入。

- 原始几何、零件身份、接口和配合证据必须真实、可追溯。
- 生成放置只使用刚体变换，不能通过缩放、镜像、变形制造不存在的零件。
- 未知、部分解析及禁用接口继续受限；单接口通过不能扩展为整件全部接口通过。
- 曲面、风挡可按已开放的表面合同参与验证，但不能据此宣称承力、闭合实体或实物稳定性已验证。
- 保留旧体系隔离，不重新开放旧参数化车型生成器。
- 复用组件与数据时继续保留适用许可和作者署名。原创整车设计不改变零件源文件的许可。

## 首个整车验收

1. 输出可辨识的跑车结构：前后轮组、低矮座舱、协调的车头车尾和车身覆盖。具体宽度、轴距和高度以真实零件与接口约束确定。
2. 风挡作为座舱的重要约束，联动宽度、高度、安装点与周边车身；选择有来源和当前权限的合适整体风挡。
3. 轮组与底盘通过真实接口连接，并分别记录最终姿态、旋转净空、安装路径和实物验证状态。
4. 每个实例均能追到准确原生身份及来源；整图、接口占用、碰撞及当前资格检查通过。
5. BOM、步骤、来源与实际模型一致；正式导出后重新导入仍通过当前检查。
6. 只有座舱、底盘或车身子模块时，明确作为阶段成果交付，不称为完整跑车。

原创外观与数字装配通过分别验收。物理稳定性、保持力和实物拼搭没有证据时继续标为未知。

## 既有车型和风挡资料的角色

S63、76924 SL 63、Ferrari 等资料保留为历史需求、真实零件检索及拼搭方法参考。它们不再是必须复现的外观模板，其精确风挡映射不作为原创跑车生成的前置条件。

已有 18973、62360、65632、65633 的两件表面合同生成见证可以用于座舱研究；不能将它们直接标为某车型的精确官方风挡。透明材质、窗框印刷及 Element/外观变体身份仍需有来源依据。

## 当前基准与下一步顺序

基准代码与实验：`23470ca`、`dcd4d2a`。此前验证了真实零件晋升及部分基础/风挡装配，尚无通过完整验证的轮组模块或原创整车。

1. 建立原创跑车的参数化设计目标：车身比例、座舱位置、轮距/轴距和覆盖区域；这些是搜索目标，不是新造零件几何。
2. 优先解决真实轮组接入与整体风挡/座舱子模块；来源不足时保留阻塞，同时推进其他可验证模块。
3. 改进接口候选排序与局部回退，让已验证零件形成底盘、横梁和侧向结构；碰撞继续负责验证。
4. 按这些结构的实际缺口扩充零件，完成整车连接图、BOM、步骤和重导入验收。
5. 在准确身份基础上改善透明玻璃、窗框与车身显示，单独记录外观效果和装配结论。

历史审计、用户示例和已有模型保持原样。本文件变更产品目标，不修改生产准入规则或继承旧验证结果。
