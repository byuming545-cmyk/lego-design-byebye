# 真实接口与拼接库

## 定位

“接口与拼接库”是现有真实零件、LDCad Shadow 接口、接口语法、正式装配引擎和普通生成器的可审查视图。它不是独立规则表，也不是展示专用目录：

- 接口类型只用于组织与筛选，名称不参与兼容判断。
- 每条接口实例都来自固定版本的 LDraw/LDCad Shadow 文件和原始指令。
- 每条规则直接读取 `src/parts/grammar/rules.ts` 的 15 条实现规则和正式 native graph 规则，不复制第二套兼容逻辑。
- 案例调用 `GrammarAssemblyService`/`AttachmentEngine`；比较调用接口语法、native compatibility、solver，并在双侧可生成时调用正式 `attach`。
- 比较、人工反馈、UI 状态都不能授予生成准入。

入口：`/#/interface-library`。顶部导航“接口与拼接库”。

## 四层记录

1. **接口类型**：25 个 `CONNECTOR_FAMILIES`，展示标签、说明、实例数、零件数、关联规则与生产状态。
2. **接口实例**：253 个真实根零件解析出的 5,085 条接口。每条包含 partId、featureId、来源引用、版本、行号、SHA-256、原始指令、局部坐标、方向、轴向、截面、尺寸、匹配策略、覆盖状态、启用状态、未知字段和诊断。
3. **关节/装配规则**：15 条 `CONNECTOR_GRAMMAR_RULES`；展示两端 family、方向条件、同轴关系、插入范围、允许转动、来源证据、负例、真实案例及当前生产边界。
4. **组合模块**：只引用现有 `BAR_CLIP`、`PIN_HOLE` 和 C01 真实案例，不新增并行的模块规则。

## API

`/api/interface-library`

| 方法 | 路径 | 内容 |
| --- | --- | --- |
| GET | `/overview` | 计数、类型、规则、案例、版本、限制 |
| GET | `/interfaces?family=&status=&coverage=&q=` | 接口实例分页列表 |
| GET | `/interface?partId=&featureId=` | 单接口详情、来源、原始指令、规则、诊断 |
| GET | `/rules` / `/rule?id=` | 规则列表/详情、条件、负例、案例 |
| GET | `/cases` / `/case?id=` | 装配案例与正式验证记录 |
| GET | `/queue` | 复核队列（接口缺口 + 未处理人工反馈） |
| POST | `/compare` | `{ partId, targetPartId? }`，只读比较，不授予准入 |
| GET/POST/PATCH | `/feedback` | 持久化人工观察与处理状态 |

反馈写入 `<data>/interface-library/feedback.json`，原子替换。记录包含时间、目标、接口/规则版本、语法/零件库/碰撞版本、来源摘要、原始软件结论、正文、署名、视图、仅链接附件（如提供）、处理状态与历史。`humanObservation` 永远为 `true`，`canAuthorizeRule` 永远为 `false`。存在 `open/triaged/needs-evidence/accepted-for-review` 反馈的规则会额外显示 `review-required` 标记和未关闭数量；该标记只进入复核，不自动撤销生产规则、开放接口或跳过碰撞。

## 页面

- **概览**：253 零件 / 5,085 接口 / 3 条生产规则 / 4 个案例；类型卡、规则状态、案例和限制。
- **接口**：家族/状态/来源筛选；真实几何 viewer；聚焦接口、全零件、透明、Z 剖面、坐标轴；来源、原始指令、尺寸、允许运动、规则、反馈。
- **规则**：条件、缺口、负例、接口样例、已验证/已阻止案例。
- **案例**：C01、BAR_CLIP、PIN_HOLE 三个正式通过案例 + 30374→60470b 真实碰撞阻止案例；显示固定/移动端、边、验证、重导入、版本和碰撞状态。
- **新零件对比**：真实接口识别 → 规则匹配 → 条件满足/失败 → 正式装配/求解/碰撞；分类 exact/candidate/conflict/insufficient；`generationAdmission` 固定为 false。
- **复核**：缺少来源、解析不完整、规则未支持、碰撞不确定、装配失败、人工争议分组；反馈可提交、刷新后仍在，可记录处理状态与历史。

## 3D 与证据边界

viewer 只使用 `NativePartViewer` 的真实 LDraw 三角面，不生成替代几何。接口高亮、方向箭头、坐标轴、透明和剖面均为参数示意；页面明确写“不是碰撞或实物证据”。案例提供“分离前 / 轴对齐 / 已就位”三态，沿来源轴向移动移动端，仅用于观察相对位置；未验证安装路径时明确标注“示意，非安装轨迹”。

## 限制

- 只有 C01、BAR_CLIP、PIN_HOLE 进入正式生产图；其余 12 条仍是条件规则。
- 多数接口族没有真实实例或没有正式规则，页面显示 0 并保持禁用，不做外观推断。
- 复核队列服务端上限 800 条，避免一次渲染全部 5,085 条；筛选/搜索可继续定位。
- 对比不会因为名称、半径或外观相同而判定兼容；没有可调用规则时返回 insufficient。
- 未实现二进制附件上传；页面明确只接受来源链接。
- 本轮没有训练模型，也没有把人工观察当作训练或自动授权。
