# 车身比例与独立覆盖件：2026-11-07

基线为现场干净 HEAD `76e2065feffb70582da5d3fe17f0ab01e8d89ea5`，工作分支 `codex/vehicle-surface-design`。没有恢复旧代码、覆盖历史模型、切换车型或发布环境。本轮仍以 **1969 Dodge Charger R/T** 验收，GTR 截图只提供覆盖连续性和积木收边工艺参照。

本轮可见改善已经实现，但没有完成高还原度 Charger，也没有完成正式整车装配。机盖、窗带和轮拱优于基线；侧面仍直、保险杠仍厚、后窗和后翼子板特征仍简化。实际对照见 [五视图对比](../artifacts/vehicle-surface-2026-11-07/comparison.html)，所有图片均由原生网格和实际实例在本地 WebGL 渲染，无生成图片替代。

## 原来的具体问题

- `body-catalog` 只允许普通板、砖、瓦和一个 2×2 斜坡，已有曲面、楔形、浅斜坡和轮拱不能进入候选。
- `body-preview` 把所有功能区域统一填成实体体素，再合并大板砖。可见表面没有单独的方向、连续性或收边目标，增加件数仍会得到横向台阶。
- 采用机盖/尾厢视觉上限、再按板高填充，实际机盖偏厚，玻璃只剩高腰线上方的窄黑带；屋顶边界选区间极值，未与原生斜坡联动。
- 前后脸是通用黑条和白/红点；面片朝向也有问题。轮拱只是近似挖空，开洞位置与车身网格原点存在一格差异，轮胎还向车外凸出。

## 改造后的机制

`body-plan` → 侧面/俯视布局诊断 → 内部窄支撑 → 独立功能外壳 → 原生几何选件和刚体姿态 → 安装候选/净空/碰撞诊断 → 实际 BOM 与五视图。

- 宽度评估 6–12 格，包含 7、9、11。轮径/总高误差、车长离散误差、可表达的侧窗高度和硬顶宽度误差共同评分。不是按车型名称返回坐标，也不把宽度固定为 8。
- 原始尺寸、视觉区间、校准假设和冲突均保留。机盖/尾厢采用区间中值，座舱端点离散到真实格距；为原生斜坡面留一格坡段，平顶与侧窗单独规划。
- 平面瓦只铺对应表面，内部只保留窄底板支撑；两侧曲面件高边朝内，前后曲面件分别朝机盖/尾厢内部升高。轮拱占用整个真实件的跨度，周边覆盖不再填进开口。
- 曲面候选检查原生包围盒及形状类别。带缺口、倒置、鳍片、台阶等件不能仅因长宽高相同而替代连续曲面。`selectionCandidates` 留存评分和实际选择。
- 轮拱候选先按原生尺寸排序，再以实际网格三角形对原生轮胎外圆柱进行保守静态筛选。50745 的尺寸最接近，却会侵入轮胎；1846 通过此有限筛选后实际用于 BOM。没有扩大碰撞容差。
- 车头根据本次真实视觉的“双黑格栅/亮边框”特征生成两个后退的暗格栅、中央分隔和独立下保险杠，封闭灯区保持暗色。没有通用白点灯、GTR 尾翼或按名称分支。灯罩、网格纹理和镀铬材料没有虚构。
- 前挡、黑色前窗柱/侧窗、白色硬顶、后窗及较宽白色后窗柱分别生成。普通黑色真实砖/斜坡表达玻璃，无新增专用风挡。
- 当前权限来自原接口准入检查。安装候选通过现有 `solveAttachment` 求真实接口姿态；没有匹配的实例明确标记 `NO_MATCHING_INSTALLATION_POSE`。数学姿态候选不写入正式连接图，也不授予资格。

## 真正改变布局和选件的约束

| 约束 | 实际作用 |
|---|---|
| 实车 5283.2×1948.2×1351.3 mm，轴距 2971.8 mm | 决定模型比例及目标轴距；8 格方案目标 433.89×160×110.98 LDU |
| 原生 18977 轮胎直径 60、宽 28 LDU | 决定宽度候选评分、轮心高度和轮拱静态筛选，不缩放轮胎 |
| 机盖/尾厢中值及 8 LDU 板高 | 机盖表面取 80，硬顶 112，形成实际可见 24 LDU 侧窗面 |
| 座舱起止及 3039/3040b 原生斜坡 | 座舱 240–360、硬顶 260–340 LDU；其边界和 45° 源坡角与原视觉冲突明确保留 |
| 轮拱源三角形和轮胎外圆柱 | 排除 50745 等侵入候选，实际选择 1846，轮位更收进车身 |
| 当前碰撞内核 | 排除与后轮拱相穿的肩部斜坡，改用平瓦；保险杠与饰件移到接触边界 |
| 视觉格栅/尾灯描述 | 改变前脸分层和尾部双红灯区，几何不依赖车型字符串 |

现有视觉还存在前/后悬与轴位、像素轴点与归一化轴位、车顶边界及玻璃角度矛盾。前挡源面为 45°，对已有 58–62° 区间误差 -15°；后窗对 48–52° 误差 -5°。原生屋顶实际宽 120 LDU，视觉区间约 131.2–140.8；车头和尾部仍离散到完整车宽 160，较视觉鼻部/尾部 140.8–150.4 偏宽。原生前端曲面使最前方平唇高 64 LDU，低于校准后鼻部约 73.2–77.9 的区间；离地 8 对设计中值约 11.2 也有误差。逐项记录见 `surface-interval-errors.json`。物理尺寸误差通过不代表这些视觉区间全部满足。

## 基线与两轮记录

完整证据在 [artifacts/vehicle-surface-2026-11-07](../artifacts/vehicle-surface-2026-11-07)。每轮都有实际模型、参数、BOM、来源、用途/旋转/证据、草稿步骤、布局 SVG、五视图与静态轮胎包络结果。

- **基线：106 件 / 23 种。** 原始模型及五视图复制保存，原目录未改。外壳台阶和凸点多、玻璃窄、前脸模板化。保守轮胎外包络检查报告 16 个相交候选；这不等于 16 个已证明的实物碰撞。
- **第一轮：117 件 / 18 种。** 独立曲面收边、平瓦机盖、斜面窗区和真实轮拱。实际渲染暴露肩部缺口、粗窗柱和饰面朝反；静态包络发现四个轮拱侵入候选。
- **第二轮最终：123 件 / 19 种。** 补齐肩部、前窗黑色边缘接入侧窗、纠正饰面朝向，并更换轮拱。二轮工程检查中曾发现同尺寸缺口曲面被误选，以及五处真实源面/实体穿插；失败模型分别保存在 `round-2/rejected-initial`、`round-2/rejected-crossings`，没有隐藏。最终修正选择/位置后重新渲染，未开展第三轮造型改进。
