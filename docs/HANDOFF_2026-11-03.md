## 6. 目前的问题

### P0：真实零件来源不可达

这是唯一阻止“新增真实生产零件”的硬阻塞。

- `3062b` 不在固定库
- 批准的 LDraw 源被网络重置
- 无真实 bundle
- 无真实 promote
- 无新增生产零件

需要下一位接手者做：

1. 拿到真实 `bundle.json` + `ldraw/parts/<id>.dat` + `shadow/parts/<id>.dat` + 依赖文件；
2. 或获得可访问的批准源 / 合法镜像；
3. 或明确本轮不做真实导入，只做代码加固。

不能手写 `.dat`、Shadow、SHA、作者或许可。

### P0：验收样例偏差

- 提示词指定 `3024 + 11477` 或 `3001 + 18973`
- 严格 soundness 后两者都失败
- 实际通过 `3001 + 11477`
- 需要确认：
  - 接受 `3001 + 11477` 作为替代；或
  - 坚持 `3024 + 11477`，继续调查其 seat 外真实交叉

### P1：post-promote 不是完整报告重建

已实现运行时审计 + ledger + JSON，但还没有自动重跑：

- connector parse audit
- interface coverage
- 全量 report/verification
- UI/API 缓存
- 旧模型 stale 标记

不能把运行时审计说成完整报告重建。

### P1：18973 仍未解决

- `18973` 的 seat 外接触/穿透仍失败
- 不应为了让样例通过而调整 seat
- 当前保留 blocked

### P1：verification.ts 仍偏 structural

- 旧 fixture 验证链没有完整适配 exterior 语义
- 不要让 exterior 模型被它误标成“闭合实体认证”
- 当前 exterior 生成走 engine.validateGraph，不走完整 fixture 认证

### P2：路径与物理

- 终点无碰撞不等于安装路径通过
- Studio 路径显示 `not-checked` / “暂时无法判断”
- 保持力、摩擦、形变、轮组保持、实物搭建都是 UNKNOWN

### P2：规则 review 与撤销

- 接口库已支持人工反馈、版本快照、处理历史
- 但“规则收到反对后自动撤销”没有接现有权限/撤销机制
