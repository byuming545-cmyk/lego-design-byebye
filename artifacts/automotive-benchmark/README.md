# V0.3 实际运行证据

- `source-required/report.json` / CSV：不允许估算，7 项车型研究待完成；没有使用演示数据代替官方尺寸。
- `estimated/report.json` / CSV：显式允许工程估算，7 组共 56 个粗方案的评分、失败与来源状态，发布 21 个通过当前数字门槛的候选。
- `estimated/models/`：本次实际输出的 28 个模型与会话 JSON，以 `.json.gz` 无损压缩，避免向代码差异中加入数百万行生成数据。所有文件均已解压并重新解析验证；原始 CLI 运行会输出普通 JSON。模型与会话互相重复部分数据，便于分别检查零件、步骤和设计上下文。
- `generator-coverage.json`：5 类车型、三种车宽、每组 5 个方案的生成器覆盖记录。
- `../automotive/manifest.json`：实际浏览器截图、渲染零件数、脚本错误与人工观察。

真实参考模型导入数为 0；实物试拼为 0。所有估算车型仍需核实官方资料。截图显示的是规则拼搭概念车，目标车型辨识尚未建立，尤其不能以几何高分证明已经复刻 S63、911 或 Revuelto。

报告中的 session ID 属于本次运行数据目录，不会随源码 ZIP 自动安装为用户数据。自己运行 `npm run benchmark:automotive -- --estimated` 会生成新会话和可在自己服务中打开的预览链接。PNG 可直接查看，不依赖临时会话。
