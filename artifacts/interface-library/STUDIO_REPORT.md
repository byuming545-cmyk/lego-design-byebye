## 限制

- 安装路径检查只做两件刚体取样，不检查连续运动、形变、卡扣/轮胎弹性、保持力或实物。
- 路径的 seat 绑定目前要求两端锚点落在合法姿态，因此分离中间帧会显示“暂时无法判断”，不会误报通过。
- 未实现二进制照片/视频上传，只保存来源链接；页面明确说明。
- 没有自动修改全局规则；人工示例不会进入正式生成。
- 齿轮、链条、皮带等机械交互仍不在普通连接图内。
