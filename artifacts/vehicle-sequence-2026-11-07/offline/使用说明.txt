Bricklab 拼搭顺序演示（草稿）· 离线查看版

1. 解压后用电脑 Chrome 或 Edge 打开 bricklab-sequence-demo.html，无需后端、密钥、CDN或网络。
2. 选择已保存的 Charger 或 Golf。离线版不执行新车型生成。
3. 保留八色、四预设及车身/车顶/饰件/轮拱独立配色。
4. 模型下方切换“拼搭顺序演示（草稿）”，点击开始演示或播放。支持上/下一步、进度、0.5–4倍速、阶段跳转及退出。
5. 每步新增1–2件。当前零件发光，之前零件正常显示，后续隐藏；相机始终按完整模型取景。没有插入轨迹动画。
6. “导出演示顺序 JSON”保存完整模型、当前配色、全部顺序、来源及未知状态。先选择相同车型，再导入重开。包内两份 sequence.json 为完整默认配色演示草稿，可导入。原配色草稿和BOM导出仍保留全部零件。
7. 浏览器保存仅保存配色，建议导出 JSON 备份。重开顺序草稿后停止播放并显示完整模型。

建议顺序演示，连接、安装路径与实物拼搭尚未完整验证。排序依据功能用途和原生几何位置，属于启发式，不是原说明书步骤。轮胎与轮毂最后逐件展示，不代表配合、底盘安装或安装时机已通过。

APPEARANCE_DRAFT；整车连接 NOT_VERIFIED；DRAFT_NOT_BUILD_INSTRUCTIONS。原始轮组、稳定性、实物及颜色供应结论均保持。原模型、零件和姿态未修改。

云端浏览器可能按管理员策略阻止 file://，请勿修改组织策略。允许的个人电脑浏览器可尝试直接打开；交付报告会分别记录文件直开限制与同一HTML的自包含检查。

开发者复现：Node24.5+，已有依赖与Python3；npm run build；npm run preview。离线重新导出：npm run export:vehicle-review -- 新目录。云端 localhost 不是用户电脑的公网地址。
